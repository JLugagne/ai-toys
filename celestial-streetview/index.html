Street View imagery

This tool draws celestial bodies on top of a real Google Street View panorama. Google charges for that imagery, so it needs your own API key — there is no server behind this page to hold one for you.

  1. Open the Google Maps Platform console and pick or create a project (billing must be enabled; Google includes a monthly free allowance).
  2. Enable the Maps JavaScript API for that project.
  3. Go to Credentials → Create credentials → API key.
  4. Restrict the key to the sites you use it from (HTTP referrer) so nobody else can spend it.

Where the key goes: it is kept in this browser’s local storage and sent only to Google when the panorama loads. This page has no backend and never transmits it anywhere else. Clear it any time with Remove key.

Without a key everything still works in Sky view: same positions, same tracks, just a plain horizon instead of a photo.
