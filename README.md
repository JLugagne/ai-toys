# AI Toys

A collection of small, single-purpose tools, published as static pages via GitHub Pages. No server, no build step required for the core site — just plain HTML/CSS/JS.

## Adding a new tool

1. Create a new folder at the repo root (e.g. `my-tool/`) containing at least an `index.html`.
2. Add a link to it from the root `index.html`.
3. Push to `main` — the GitHub Actions workflow publishes the site automatically.
